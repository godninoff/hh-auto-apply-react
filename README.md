# HH Auto Apply — React + TypeScript

## Установка

```bash
npm install
npm run check
npm run build
```

После сборки открой `chrome://extensions`, включи «Режим разработчика», нажми «Загрузить распакованное расширение» и выбери папку `dist`.

## Важно

Это новая базовая реализация на React + TypeScript, а не механическая упаковка старых JS-файлов. Она сохраняет основной сценарий: список вакансий → отдельная вкладка → заполнение письма → отправка → возврат к списку; опросник оставляет вкладку открытой.

Поведение сайта hh.ru может меняться. Перед массовым запуском проверь работу на одной вакансии.
